# Parked Continuations

The parking lot. Each row is a task that was deliberately stopped mid-flight with enough of a briefing that a **cold future session** — no memory of the conversation that parked it — can pick it up and keep going.

- Park a task with [Protocol 12](../protocols/12-park.md): *"park this."*
- Resume one with [Protocol 13](../protocols/13-pickup.md): *"pick up `<slug>`."*

One task gets one slug and one file, updated in place. Re-parking an unfinished pickup is expected — that is how the doc stays true.
